# Employee Desktop App

Employee Management Desktop App built with Electron, HTML, CSS, and JavaScript. Supports employee CRUD operations (Create, Read, Update, Delete), data persistence using Local Storage, and a responsive UI.

## Features

- Add Employee
- Edit Employee
- Delete Employee
- View Employee List
- Persist Data using Local Storage
- Responsive Dialog-based UI
- Clear All Employees
- Data Reload on Application Restart

## Employee Details

The application stores the following employee information:

- Name
- Age
- Gender
- Company
- Location

## Tech Stack

- Electron
- HTML5
- CSS3
- JavaScript (ES6)
